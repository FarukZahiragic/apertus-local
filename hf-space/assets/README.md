# Apertus brand assets

The unmodified `apertvs.svg` wordmark and `favicon.svg` are from the official
[Apertus website](https://www.apertus-ai.org/), maintained by the Swiss AI Initiative.
They identify the model used by this independent workshop project.

Source: [swiss-ai/www-apertus](https://github.com/swiss-ai/www-apertus/tree/17b780bf65b0208cb081d6686018950c51bfaea3/static),
revision `17b780bf65b0208cb081d6686018950c51bfaea3`, checked 2026-11-09.
Original paths: `static/images/apertvs.svg` and `static/favicon/favicon.svg`.
The assets remain the work of their respective owners.

The live homepage uses a pale blue `#c9eef5` to white background, cyan
`#49bed8` navigation accents, and dark `#13171c` wordmark paths. The local
stylesheet uses these colours with darker teal text for readable contrast.
The assets are served locally so page rendering does not depend on the upstream
website or a font CDN. This project is not an official Swiss AI service.
