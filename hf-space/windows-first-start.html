WINDOWS · LOCAL CHAT

First start on Windows

Use 64-bit Windows 10 or later. We recommend 16 GB RAM. No WSL, Python, compiler, GPU or paid account is needed.

  1. Choose your processor. Use the Intel / AMD download for most PCs, or ARM / Snapdragon for ARM PCs. Find the system type under Settings → System → About.

  2. Extract the whole ZIP. Right-click it and choose Extract All. Open the extracted folder. Run files from that folder.

  3. Double-click Start.cmd. Keep its window open. The first start downloads and verifies the model files (5.3 GiB language model plus 872 MiB image/audio encoders), then opens local browser chat.

  4. Chat offline after preparation. Later starts reuse the checked model. Press Ctrl+C in the window or open Stop.cmd to stop and release the model's memory.

The package works with the built-in Windows PowerShell 5.1. Its launcher uses a process-only execution-policy option; it does not change your saved policy. This is an unsigned preview. If Windows or your organization blocks it, follow your organization's installation rules or ask the organizer. Keep security tools enabled.

Already have the model? Copy apertus-v1.5-8b-Q4_K_M.gguf into %LOCALAPPDATA%\Apertus Local\models\ before starting. For image/audio input, also copy apertus-v1.5-8b-mmproj-F32.gguf there. Logs are saved under %LOCALAPPDATA%\Apertus Local\state\.

If using a USB drive, use a filesystem that supports files larger than 4 GB, such as exFAT.
