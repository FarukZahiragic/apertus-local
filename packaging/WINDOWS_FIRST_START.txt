Apertus Local - Windows local chat

Windows 10 or later with built-in Windows PowerShell 5.1 (PowerShell 7 also works).
Use the ZIP matching your processor: x86_64 for Intel/AMD, ARM64 for Snapdragon.
16 GB RAM is recommended. No Python, WSL, compiler or paid membership is needed.

1. Extract the whole ZIP into a folder. Do not run files from inside the ZIP.
2. Double-click Start.cmd. It opens a window showing preparation and startup.
3. Stay online for the first model download (5.3 GiB plus 872 MiB image/audio
   encoders). The launcher checks both
   checksum and opens local browser chat when ready. Interrupted downloads resume
   when you start it again.
4. Keep the window open while chatting. Press Ctrl+C or double-click Stop.cmd
   to stop. Later starts use the verified model and work offline.
5. Use the chat attachment button for an image or a short audio clip. Start with
   one clear image or less than 15 seconds of speech. The answer is text.
   Use Start-Text.cmd when you want text chat without loading the encoders.

The scripts run with a process-only execution-policy option; they do not change
your saved PowerShell policy. Managed organization policies still apply.
This preview is unsigned. If Windows or your organization blocks it, follow your
organization's installation rules or ask the organizer. Keep security tools on.

User data and logs: %LOCALAPPDATA%\Apertus Local\
To reuse a model from USB, copy apertus-v1.5-8b-Q4_K_M.gguf into the models folder
there before starting. USB media must support files larger than 4 GB, e.g. exFAT.
For image/audio input, also copy apertus-v1.5-8b-mmproj-F32.gguf there.

Developer overrides: PORT, THREADS, CTX, MODEL, MODEL_SHA256, MODELS_DIR,
APERTUS_STATE_DIR, BUILD_DIR. CPU features are detected by the native runtime.
No GPU is required. Performance depends on the processor, memory and other apps.
