Apertus Local — first start on a Mac

Requirements: Apple M-series chip, macOS @MACOS_MINIMUM@ or newer; 16 GB RAM recommended.
No Apple Developer membership, Homebrew, Python or compiler installation is needed.

1. Extract the ZIP. Move Apertus Local.app into Applications or another permanent
   folder, then double-click it.
2. This unsigned preview has not been notarized by Apple. If macOS says the
   developer cannot be verified or the app was not checked, dismiss that alert.
3. Open System Settings > Privacy & Security. Scroll to Security and choose
   Open Anyway for Apertus Local. Confirm the next prompt; macOS may ask for
   your login password or Touch ID. Approve only the app you intentionally
   downloaded from the project's release page. Your Mac normally remembers this
   exception for subsequent starts of this copy of the app.
4. If asked, allow Apertus Local to control Terminal. Its Terminal window shows
   startup progress; keep it open while chatting.
5. On the first start, the launcher downloads and verifies the 5.3 GiB model.
   Leave internet access on until this finishes. It then opens local browser chat.
6. Press Control+C in the Terminal window to stop. Open the app again to restart.
   Once the model is prepared, local chat works without an internet connection.

Apple describes per-app approval at https://support.apple.com/en-us/102445.
Do not disable system-wide security checks. If a managed Mac offers no approval
button, ask its administrator. A warning that the app contains malware or has
been damaged is a different problem: stop and contact the workshop organizer.
